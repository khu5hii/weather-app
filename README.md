# 🌤️ Retro Weather Station

**Get 8-bit style weather data for any city!**

Step back in time with our retro-themed weather app. Designed with a pixelated 8-bit aesthetic, it brings classic gaming vibes while delivering real-time weather data.

---
## 🌐 Live Website

👉 **Live Demo:**  https://retrocast.onrender.com/

---
## 🎮 Features

- **Retro 8-bit UI**: Nostalgic, pixel-perfect interface with pastel gradients and retro fonts.  
- **City-based weather search**: Enter any city to fetch live weather info.  
- **Weather details**:  
  - Temperature (°C)  
  - Weather condition  
  - Humidity (%)  
  - Wind speed (kph)  
- **Responsive design**: Works on desktops, tablets, and mobile screens.  
- **Loading skeletons**: Animated placeholders while fetching data.  
- **Keyboard & button support**: Press Enter or click Search to get weather updates.

---

## 🕹️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Node.js, Express.js  
- **API**: [WeatherAPI](https://www.weatherapi.com/)  
- **Environment variables**: `.env` file for API keys  

---

## 🖥️ Usage

1. Enter a city name in the input box.  
2. Click **SEARCH** or press **Enter**.  
3. Watch the retro animation while data loads.  
4. See your city’s **temperature, condition, humidity, and wind speed** displayed in 8-bit style!  

---

## 🎨 Design Notes

- **Fonts**: Jersey 10, inspired by retro game UI  
- **Colors**: Pixel-perfect gradients reminiscent of classic games  
- **Icons**: Custom pixel-art icons for humidity, wind, and weather
